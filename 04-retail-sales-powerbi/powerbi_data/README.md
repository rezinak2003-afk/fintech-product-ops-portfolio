# Power BI import data

These six CSVs are already populated and can be imported directly with **Home → Get data → Text/CSV** in Power BI Desktop. They use aggregate facts rather than the full customer-level transaction file, which keeps the public portfolio repository small. Use `POWER_BI_BUILD_GUIDE.md` for the three-page report design, slicer recommendations, and DAX measures. All aggregate table provenance and limitations are documented in `../data/DATA_PROVENANCE.md`.

Files: `MonthlyRevenue.csv`, `CountryRevenue.csv`, `TopProducts.csv`, `MonthlyReturns.csv`, `RFMSegments.csv`, `CohortMonth1Retention.csv`.
