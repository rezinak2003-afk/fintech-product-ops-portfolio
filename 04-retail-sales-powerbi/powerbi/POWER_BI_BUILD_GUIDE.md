# Power BI build guide — Retail Sales & Customer Analytics

## Current handoff status
All six Power BI CSVs are populated and included under `powerbi_data/`. The static interactive web dashboard is fully built and reads included JSON data immediately. A native `.pbix` file must be created/saved by Power BI Desktop; its binary report/model format cannot be reliably generated by this project packaging environment, so no fake `.pbix` is included.

## Import
In Power BI Desktop, the quickest option is **Home → Get data → Excel workbook** and select `PowerBI_Import_Pack.xlsx`; use the `MonthlyRevenueTable`, `CountryRevenueTable`, `TopProductsTable`, `MonthlyReturnsTable`, `RFMSegmentsTable` and `CohortRetentionTable` entries in Navigator. Alternatively use **Home → Get data → Text/CSV** and import all six CSVs from `powerbi_data/`:
- `MonthlyRevenue.csv`
- `CountryRevenue.csv`
- `TopProducts.csv`
- `MonthlyReturns.csv`
- `RFMSegments.csv`
- `CohortMonth1Retention.csv`

Keep types numeric for revenue, invoices, percent columns and counts. Month/cohort_month should be text initially (`YYYY-MM`) to preserve sorting; add a proper month-start date in Power Query if preferred.

## Page 1 — Executive sales overview
- KPI cards: Total Revenue GBP, Total Invoices, Average Invoice Value GBP.
- Line chart: `MonthlyRevenue[month]` vs `MonthlyRevenue[revenue_gbp]`.
- Bar chart: `CountryRevenue[country]` vs `CountryRevenue[revenue_gbp]` (Top N 10).
- Bar chart: `TopProducts[description]` vs `TopProducts[revenue_gbp]` (Top N 10).
- Line or column chart: `MonthlyReturns[month]` vs `MonthlyReturns[return_rate_pct]`.
- Slicers: Month/Year, Country (country slicer only filters country table unless transaction-level tables are related).

## Page 2 — Customers & retention
- Bar chart: `RFMSegments[segment]` vs `RFMSegments[pct_revenue]`.
- Bar chart: `CohortMonth1Retention[cohort_month]` vs `CohortMonth1Retention[retention_pct]`.
- Table: cohort month, cohort size, active customers in month 1, retention percentage.
- KPI cards: Champions revenue share, combined Champions + Loyal Customers share, average month-1 cohort retention.

## Page 3 — Data quality & recommendations
- Include the methodology, source citation, aggregate table limitations and the incomplete December 2011 warning.
- Explain that the aggregates are historical and are not real-time or causal.

## Measures
Use `PowerBI_Measures.dax` as a measure reference. If Power BI creates different table names, adjust the references. The workbook contains named tables such as `MonthlyRevenueTable` and `CountryRevenueTable`; the DAX references use those exact table names. The provided CSVs contain pre-aggregated tables; slicer cross-filtering between unrelated grains should not be implied. For full slicing across all visuals, rebuild from a transaction-level import using the Python pipeline's outputs.

## Save / publish
Save as `Retail_Sales_Customer_Analytics.pbix`. Publish through Power BI's available options only after checking tenant settings and public-sharing implications. Do not publish private or restricted data to the public web.
