# Retail Sales & Customer Analytics (Power BI + SQL + Web Dashboard)

**Dataset:** UCI Machine Learning Repository — Online Retail (CC BY 4.0). Source transactions span 1 Dec 2010–9 Dec 2011. Dataset source and citation: https://archive.ics.uci.edu/dataset/352/online+retail and https://doi.org/10.24432/C5BW33.

This is a reproducible portfolio project. It contains the cleaning/aggregation pipeline, SQL analysis, Power BI model instructions and a GitHub Pages-compatible web dashboard. The raw UCI workbook and resulting metrics are intentionally not fabricated or bundled. Run the pipeline on your computer to fetch the public dataset and generate the real CSV/JSON outputs.

## What the project answers
- How do sales, order volume and average order value change by month?
- Which countries and products contribute most revenue?
- How many sales lines/invoices are cancellations or returns?
- How do returning customers behave by first-purchase cohort?

## Quick start (Windows 10/11)
1. Install Python 3.10+ from https://www.python.org/downloads/windows/ and select **Add python.exe to PATH**.
2. Open this project folder in File Explorer.
3. Double-click `RUN_PIPELINE.bat`. It creates a virtual environment, installs requirements, downloads Online Retail through the UCI `ucimlrepo` client when possible, and exports Power BI files, a SQLite database, a quality report and website data.
4. If automatic fetch fails, download `Online Retail.xlsx` from the official UCI link above and save it to `data/raw/Online Retail.xlsx`, then run `RUN_PIPELINE.bat` again.
5. Open `powerbi_data/` to import the generated CSVs into Power BI Desktop. Follow `POWER_BI_BUILD_GUIDE.md`.
6. Open `site/index.html` in a browser to preview the dashboard locally. The online GitHub Pages version needs the generated `site/data/dashboard_data.json` committed with the HTML.
7. Follow `DEPLOY_TO_EXISTING_GITHUB.md` to add this folder to your existing repository without replacing other projects.

## Outputs generated by the pipeline
- `powerbi_data/fact_sales.csv` — positive, non-cancelled transaction lines used for sales KPIs
- `powerbi_data/dim_customer.csv` — customer first purchase and cohort month
- `powerbi_data/dim_product.csv` — product descriptions and stock codes
- `powerbi_data/dim_date.csv` — calendar table
- `powerbi_data/monthly_sales.csv`, `country_sales.csv`, `product_sales.csv`
- `powerbi_data/monthly_cohort_retention.csv` — customer cohort size and monthly return rate
- `powerbi_data/cancellations.csv` — cancellation/negative-quantity lines for separate monitoring
- `data/processed/online_retail.sqlite` — SQLite tables for the included SQL scripts
- `data/processed/data_quality_report.json` — row counts and exclusion checks
- `site/data/dashboard_data.json` — real aggregates for static web dashboard

## Definitions and caveats
- Revenue is `Quantity × UnitPrice` for positive-quantity, positive-price lines whose invoice number does not start with `C`, and whose invoice date parses successfully.
- Cancelled/negative-quantity lines are excluded from positive-sales revenue and exported separately; they are not silently treated as sales.
- Customer ID is optional in the source. Sales metrics include valid order lines even when CustomerID is missing; customer retention and cohort metrics require a non-missing customer ID.
- This dataset is historic (2010–2011), not current business performance. The results describe this dataset only and should not be presented as current market evidence.
- Revenue is in GBP (£), as the UCI source describes UnitPrice in sterling.
