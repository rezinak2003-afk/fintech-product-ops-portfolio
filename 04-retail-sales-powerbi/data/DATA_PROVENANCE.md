# Data provenance and attribution

## Official dataset
- **Dataset:** Online Retail II
- **Publisher:** UCI Machine Learning Repository
- **DOI / citation:** Chen, D. (2019). *Online Retail II* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CG6D
- **Dataset page:** https://archive.ics.uci.edu/dataset/502/online+retail+ii
- **License:** Creative Commons Attribution 4.0 International (CC BY 4.0)
- **Period:** 1 December 2009 to 9 December 2011

## Aggregate data shipped with this project

To make the static dashboard functional immediately, the `data/aggregate/*.csv` files and `data/dashboard_data.json` use precomputed aggregate outputs published by the public repository [`ndkn-code/online-retail-analytics`](https://github.com/ndkn-code/online-retail-analytics). The source repository states that its metrics were computed from the UCI Online Retail II dataset and exposes the aggregate extract tables used here, including monthly revenue, revenue by country, top products, returns, RFM segments, and cohort retention.

Relevant published extract URLs:
- https://raw.githubusercontent.com/ndkn-code/online-retail-analytics/main/dashboards/extracts/01_revenue_by_month.csv
- https://raw.githubusercontent.com/ndkn-code/online-retail-analytics/main/dashboards/extracts/02_revenue_by_country.csv
- https://raw.githubusercontent.com/ndkn-code/online-retail-analytics/main/dashboards/extracts/03_top_products.csv
- https://raw.githubusercontent.com/ndkn-code/online-retail-analytics/main/dashboards/extracts/04_returns_by_month.csv
- https://raw.githubusercontent.com/ndkn-code/online-retail-analytics/main/dashboards/extracts/05_rfm_segments.csv
- https://raw.githubusercontent.com/ndkn-code/online-retail-analytics/main/dashboards/extracts/06_cohort_retention_long.csv

The packaged extracts are **adapted aggregates with attribution**, not a raw-data download and not an independent recomputation in this environment. The aggregate tables omit customer identifiers and are small enough for a public GitHub Pages deployment. The raw UCI workbook is not included. `scripts/rebuild_from_uci.py` provides a reproducible pipeline to fetch the official Online Retail II workbook and recompute outputs locally when network and Python dependencies are available. If you publish results regenerated with that script, use the new output files generated by your run and update this note accordingly.

## Important interpretation notes
- Revenue is GBP and is based on cleaned positive sales lines in the published analysis.
- Cancellations/returns are analyzed separately.
- Monthly sales and monthly returns table extracts share the same sales-period basis.
- December 2011 is a partial month ending on 9 December 2011; its monthly return-rate value is not comparable to a complete month without exposure adjustment.
- Different cleaning rules can produce different totals. Refer to the cleaning rules in the source analysis before comparing figures across projects.
